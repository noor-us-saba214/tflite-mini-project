EcoSort AI (Smart Waste Classification) is an Artificial Intelligence and Computer Vision-based system designed to automatically analyze and classify waste items into categories such as Recyclable, Organic, and Non-Recyclable.

How It Works:

Input: The user uploads an image of a waste item or captures one using a camera.

AI Processing: A Deep Learning model analyzes the visual features to identify the type of waste.

Output: The system instantly displays the correct waste category along with proper disposal or recycling instructions.

Goal:
To simplify waste sorting, reduce landfill waste, and encourage sustainable recycling practices through AI automation
